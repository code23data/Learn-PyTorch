## 🚀 Getting Started
1. Clone the repository
  ```bash
  git clone https://github.com/code23data/Learn-PyTorch.git
  cd Learn-PyTorch
  ```

2. Create a virtual environment (optional)
  ```bash
  python -m venv .venv
  ```

  Activate it:
  
  **Windows**
  
  ```bash
  .venv\Scripts\activate
  ```
  
  **macOS / Linux**
  
  ```bash
  source .venv/bin/activate
  ```
3. Install the dependencies
  
  Install PyTorch using the instructions appropriate for your operating system and hardware at [pytorch.org](https://pytorch.org/).
  
  Install Jupyter and the other packages you need:
  
  ```bash
  pip install jupyter numpy matplotlib torchvision
  ```
4. Launch Jupyter Notebook
  ```bash
  jupyter notebook
  ```
  
  Open a notebook from the notebooks/ directory and run the cells.
